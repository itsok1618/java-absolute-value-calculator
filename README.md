


# Absolute Value Calculator (Java)

A simple Java console application that calculates the absolute value of any integer entered by the user using conditional `if-else` logic.

## 🚀 Try it Online!
You can run and test this application directly in your browser without installing anything:
👉 [Click here to run the program](https://onlinegdb.com/u8zhWyjgZ)

## Technical Skills Demonstrated:
- Conditional Logic (`if`, `else if`, `else`)
- User Input Handling (`Scanner` class)
- Basic Arithmetic Operations (Multiplication by -1)
